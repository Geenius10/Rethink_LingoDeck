RETHINK. LingoDeck – kompletter Neuaufbau

Diese Version wurde von Grund auf neu geschrieben.

Enthalten:
- iPhone/iPad PWA
- feste Tabbar
- Sprachordner mit Long-Press-Bearbeitung
- Ordner direkt beim Kartenerstellen anlegen, Entwurf bleibt erhalten
- Wörter und ganze Sätze
- Karte antippen -> Vorschau -> Bearbeiten -> Löschen
- Lernrichtung V→R, R→V oder 🔀 Zufall
- Lernkarte zeigt die jeweilige Sprache oben rechts
- Bewertung Nochmal / Schwer / Gut / Leicht
- Wiederholungen nach aktiver App-Zeit
- Dark Mode mit kontrastreichen Buttons
- externes Backup via iOS Teilen/Dateien + Backup laden
- getrenntes Löschen von Lernfortschritt oder allen Daten

Installation:
Inhalt über HTTPS bereitstellen und auf iPhone/iPad in Safari über
Teilen > Zum Home-Bildschirm installieren.
